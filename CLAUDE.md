\# Project Guidelines (Centralized Research Workspace)



\## Execution Rules

\- Be extremely concise. Minimize conversation; output only necessary code/commands.

\- Never write test classes unless explicitly asked.

\- Do not make assumptions about database schemas or models. Follow exact entity specs given in prompts.
